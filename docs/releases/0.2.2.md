# Joinery 0.2.2

Version: `0.2.2` · Godot base: `4.7.2-stable` · Unsigned preview release.

A bug-fix release. Everything else is as in [0.2.1](0.2.1.md) and
[0.2.0](0.2.0.md), including installing, upgrading and the known limits.

## Fixed

- Creating a new project in a folder that already held a game overwrote it.
  The New project wizard only warned that the folder was not empty, then
  wrote a new `project.godot`, export presets, icon, `.gitignore`,
  `.gitattributes` and `.editorconfig` over the old ones and merged its
  starting point into the game. The wizard now needs an empty folder (a
  `.git` folder is fine). A folder with a `project.godot` says "This folder
  already has a Godot project. Open it from the project list, or pick an
  empty folder." Any other folder with files in it says "This folder isn't
  empty. Pick an empty folder for a new game, so nothing already in it gets
  overwritten." Create stays off in both cases (engine patch 0024,
  Joinery-only).
- `joinery game apply` no longer changes a game Joinery didn't make. When a
  folder has no Joinery game record yet and its `project.godot` starts
  another scene or is set up for C#, or it has C# or .NET project files, or
  scripts and scenes the starting point doesn't ship, it stops before
  writing anything and says what it found.
- The first time a starting point goes into a folder, Joinery copies the
  `project.godot`, `export_presets.cfg` and `joinery.toml` it is about to
  change to `.joinery/backup/<time>/` and says so. These copies are kept
  out of git.

## Changed

- The art bible the New project wizard drafts from your own answers now
  counts as approved, so art and audio work can start right away. The wizard
  says "Wrote the art bible from your answers. It counts as approved, so art
  and audio work can start. If it changes later, approve it again in /art."
  A later change to the bible still needs your one-click Approve in `/art`,
  a draft with required sections left unset still needs finishing first, and
  Journeyman still cannot approve it (ADR 0033).
