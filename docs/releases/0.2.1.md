# Joinery 0.2.1

Version: `0.2.1` · Godot base: `4.7.2-stable` · Unsigned preview release.

A bug-fix release for Windows. Everything else is as in
[0.2.0](0.2.0.md), including installing, upgrading and the known limits.

## Fixed

- Windows: the editor no longer stops at startup with error 0xC0000409.
  On the first launch of a fresh project, Godot rebuilds its script
  documentation on two background threads, and both could wait for the same
  thread to finish. When the wrong one got there first, the editor aborted.
  Only the main thread waits for it now (engine patch 0023,
  `editor/doc/editor_help.cpp`). This is a Godot bug, not specific to
  Joinery, and the patch is written to be offered upstream.
- Windows: cancelling an agent request no longer fails when one of the
  agent's child processes keeps running after it is asked to stop. Children
  still running after the wait are now stopped, then given a moment to
  release their files.

## Checks run for this release

- The Windows startup check that crashed in 4 of 10 runs before the fix ran
  30 times across three CI runs with no crash.
- A crashing Windows test editor now prints its own stack trace in CI
  (Joinery-only test patch 0022, on only when `JOINERY_CRASH_TRACE` is set),
  because Windows recorded nothing for this kind of abort. Release builds do
  not turn it on.
- The release workflow runs the unit tests, native editor checks, bundles,
  exported games and secret scan on macOS, Linux and Windows for the tag.
