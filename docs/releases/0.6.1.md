# Joinery 0.6.1

Version: `0.6.1` · Godot base: `4.7.2-stable`

Changes since [0.6.0](0.6.0.md):

## Journeyman

- **Message history in the message box.** Up brings back the message you sent
  before, further Ups go further back and Down comes forward, as in a shell.
  Down past the newest, or Escape, puts back what you had typed, so a draft is
  never lost. The history is the chat's own requests, so a saved chat you open
  again recalls what was sent in it; a message sent twice in a row comes back
  once, and commands that run in the sidebar (`/doctor`) are left out. Edit a
  recalled message and send it, and it goes as a new message. In a message of
  several lines the arrows move the caret until the first or last line, and
  while the `/` menu is open the arrows stay the menu's.
- **Switch agent in Settings.** Settings → Replies → **Switch agent** opens the
  Connect screen on the agent you use now; pick another (Codex, Claude Code,
  Gemini CLI, opencode) and the chat restarts with it. Before, the editor
  offered it only while no agent was connected.

## Fixed

- **Claude Code could not use Joinery's tools.** Claude Code 2.1.321 names the
  MCP server of a tool call as an object, and the shared policy hook read the
  whole object as the server's name, so every `joinery-registry` call was
  refused as "not enabled for this project". The hook now reads the name from
  either form; servers that aren't enabled are still denied and generative ones
  still stop the turn.
- **Your message's bubble hugs its text.** A one-line request no longer has an
  empty band under it, its padding is even on every side, and the **…** menu
  sits level with the text.
- **An out-of-date worker says so.** A worker image built before an update said
  "worker missing" or "not built"; it now says the offline worker is out of date
  after an update. **Rebuild** fixes it as before.
